# Photo prints · travel posters

Drop the five travel-poster JPGs into this folder with these exact filenames so
the products in `data.jsx` resolve them:

- `cape-town.jpg`     · Cape Town, South Africa
- `florence.jpg`      · Florence, Italy
- `london.jpg`        · London, United Kingdom
- `philadelphia.jpg`  · Philadelphia, Pennsylvania
- `tampa.jpg`         · Tampa, Florida

Recommended: long-edge ~1600px, sRGB, ~80% JPEG quality (~250–500 KB each).
The product card crops to a 4:5 aspect ratio (`object-fit: cover`), so portrait
or square sources work best — landscape images will be cropped on the sides.
